# O’ Panier Lucianais

Site vitrine de l’épicerie de village O’ Panier Lucianais, 4 av. du Quai, 34725 Saint-Saturnin-de-Lucian.

- Page unique en HTML/CSS/JS, sans dépendance externe ni cookie.
- Précommande : le message est préparé dans le navigateur puis envoyé par SMS depuis le téléphone du client. Aucun paiement en ligne, aucune donnée stockée.
- À compléter avant diffusion large : horaires, mentions légales (exploitant, SIRET, hébergeur).
