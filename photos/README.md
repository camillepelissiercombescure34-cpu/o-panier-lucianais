# Dossier photos

Déposez ici les photos de l’épicerie (glisser-déposer sur GitHub : « Add file » > « Upload files »). Le site les détecte automatiquement, aucune modification de code n’est nécessaire.

Noms attendus, en .jpg, 1600 px de large maximum, moins de 400 Ko chacune :

- `hero.jpg` : grande image du haut de page (devanture ou rue, format paysage)
- `devanture.jpg` : la façade, avenue du Quai
- `rayons.jpg` : les rayons, fruits et légumes
- `produits.jpg` : charcuteries, produits locaux
- `sandy.jpg` : l’accueil au comptoir (avec l’accord de la personne photographiée)
- `village.jpg` : le village, les vignes ou les sentiers

Seules les photos présentes s’affichent. N’utilisez que des photos dont vous détenez les droits.
